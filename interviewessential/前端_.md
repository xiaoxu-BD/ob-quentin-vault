```javascript
async function getDogImage() {
    try {
        console.log("正在请求狗狗图片...");

        // 1. 发起请求 (fetch 返回一个 Promise)
        const response = await fetch('https://dog.ceo/api/breeds/image/random');

        // 2. 解析 JSON (response.json() 也返回一个 Promise)
        const data = await response.json();

        // 3. 打印结果
        console.log("成功获取到数据：", data);
        console.log("图片链接在这里：", data.message);
        
        // 在页面上展示这张图
        const img = document.createElement('img');
        img.src = data.message;
        img.style.width = '300px';
        document.body.appendChild(img);

    } catch (error) {
        // 如果断网了或者 URL 错了，会跑到这里
        console.error("哎呀，出错了：", error);
    }
}

getDogImage();
```

# 安装 NODE


```plain
# 下载 Node.js 安装包（这里以 Node.js 18.x 为例，可根据需要修改链接）
$downloadUrl = "https://nodejs.org/dist/v18.16.0/node-v18.16.0-x64.msi"
$downloadPath = "D:\dev\node\node-v18.16.0-x64.msi"
Invoke-WebRequest -Uri $downloadUrl -OutFile $downloadPath

# 安装 Node.js
Start-Process -FilePath $downloadPath -ArgumentList "/qn INSTALLDIR=`"D:\dev\node`"" -Wait

# 在 D:\dev\node 目录下新建 node_global 和 node_cache 文件夹
New-Item -ItemType Directory -Path "D:\dev\node\node_global" -Force
New-Item -ItemType Directory -Path "D:\dev\node\node_cache" -Force

# 设置 npm 的 prefix 和 cache
npm config set prefix "D:\dev\node\node_global"
npm config set cache "D:\dev\node\node_cache"

# 设置环境变量
$env:Path = [System.Environment]::GetEnvironmentVariable("Path", "Machine") + ";D:\dev\node\node_global"
[System.Environment]::SetEnvironmentVariable("Path", $env:Path, "Machine")
[System.Environment]::SetEnvironmentVariable("NODE_PATH", "D:\dev\node\node_global\node_modules", "Machine")

# 配置镜像站
npm config set registry http://registry.npm.taobao.org



脚本首先从 Node.js 官网下载指定版本的安装包到 D:\dev\node 目录。

然后使用 Start-Process 以静默方式安装 Node.js 到 D:\dev\node 目录。

在 D:\dev\node 目录下创建 node_global 和 node_cache 文件夹。

使用 npm config set 命令设置 npm 的全局安装路径和缓存路径。

设置系统环境变量 Path 和 NODE_PATH。

最后配置 npm 的镜像站为淘宝镜像。
```
