# 元旦

1. 交通大学7号左拐  进入到淮海中路 向东走 到达上海**武康大楼**
2. 顺着武康路一直走 7分钟到达 ->江苏路地铁口(到达愚园路) ->精华路段: 江苏路地铁 到中山地铁
3. 逛到头 进入到中山公园站 两站到达静安寺(13B)出来上天桥 拍完直接还是13b坐地铁
4. 四站之后 天潼路(3号口)出门右拐 : 上海邮政博物馆 -> 直走 乍浦路桥
5. 依旧天潼路(3) 两站 到豫园 (1号)右拐 城隍庙 /豫园
6. 之后往东骑行 : 复兴东路渡口 (东昌路方向) -> 上海 2元轮渡 : 黄浦江
7. 之后下船直走: 八分钟 陆家嘴 三件套   还有天桥 => 东方明珠
8. 之后 陆家嘴站 => 南京东路(1) 出来南京东路步行街  走到头 => 外滩 











1. **交通大学（7号口）** → 左拐进 **淮海中路** → 东行至 **武康大楼**
2. 武康大楼 → 进入 **武康路** → 步行约7分钟 → **江苏路地铁站**
3. 江苏路地铁站 → 步行进入 **愚园路精华段**（至中山公园地铁站附近）
4. 愚园路尽头 → **中山公园地铁站** → 乘 **地铁2号线**（往浦东机场方向）2站 → **静安寺站（13B口）**
5. 静安寺站13B口 → 上天桥拍照 → 同站乘地铁2号线 4站 → **天潼路站（3号口）**
6. 天潼路3号口 → **上海邮政博物馆** → 直走 → **乍浦路桥**
7. 天潼路站 → 地铁2号线 2站 → **豫园站（1号口）** → 右拐进 **城隍庙/豫园景区**
8. 豫园 → 东行骑行/步行至 **复兴东路渡口** → 乘 **2元轮渡** → **东昌路渡口**
9. 东昌路渡口 → 步行约8分钟 → **陆家嘴**（三件套+天桥+东方明珠）
10. 陆家嘴站 → 地铁2号线 → **南京东路站（1号口）** → **南京东路步行街** → 走到头 → **外滩**

## **⏰**** 时间表建议（适合一日轻松游）**
| 时间段 | 行程 | 内容与贴士 |
| --- | --- | --- |
| **08:30-09:30** | 出发 & 武康大楼 | 交通大学7号口出发，步行至淮海中路→武康大楼拍照（早晨光线柔和） |
| **09:30-10:30** | 武康路漫步 | 顺武康路走，感受老洋房氛围，可在网红转角拍照 |
| **10:30-11:30** | 愚园路精华段 | 江苏路站进愚园路，慢逛历史建筑与小店（适合拍人文） |
| **11:30-12:00** | 中山公园站换乘 | 地铁2号线两站到静安寺，路上可休息 |
| **12:00-12:40** | 静安寺天桥拍照 | 静安寺站13B口上天桥拍城市景观，可顺便吃简餐 |
| **12:40-13:30** | 邮政博物馆 & 乍浦路桥 | 天潼路站3号口出，先看邮政博物馆，再到乍浦路桥拍苏州河景 |
| **13:30-14:30** | 豫园城隍庙 | 地铁2号线两站到豫园站，逛老街、尝小吃（南翔小笼等） |
| **14:30-15:30** | 骑行至轮渡口 | 豫园→复兴东路渡口（骑行约15-20分钟），体验2元轮渡 |
| **15:30-16:30** | 陆家嘴三件套 | 东昌路渡口步行至陆家嘴，拍三件套+天桥全景，可选登塔 |
| **16:30-18:30** | 南京东路步行街 | 地铁回南京东路站，逛步行街购物+小吃 |
| **18:30-20:00** | 外滩夜景 | 步行街尽头入外滩，看万国建筑灯光与黄浦江夜景（冬季亮灯约17:00-23:00） |
